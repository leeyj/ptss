# PTSS 업데이트 히스토리

### [v1.2.0] - 2026-02-18
#### 추가된 기능 (Added)
- **세션 유지 및 자동 복구 (Persistence Layer)**: 브라우저 새로고침이나 일시적인 연결 끊김 시에도 서버 측에 터미널 세션과 출력 백로그(최근 2000줄)를 유지하여 작업 흐름을 완벽히 보존함.
- **명령어 스니펫(Snippet) 관리**: 자주 사용하는 명령어를 카테고리별로 저장하고 클릭 한 번으로 터미널에 전송하는 기능 추가. 단독 뷰 및 복합 뷰 모드 지원.
- **터미널 개인화 설정**: 환경 설정 메뉴를 통해 5종의 유명 테마(Default, Monokai, Dracula 등)와 폰트 종류, 크기(10~24px)를 자유롭게 변경 가능.
- **터미널 로그 저장**: 각 터미널 탭에 '저장(💾)' 버튼을 추가하여 현재 세션의 모든 입출력 내역을 `.txt` 파일로 다운로드 가능.
- **사이드바 토글(Collapse)**: `☰` 버튼을 통해 왼쪽 메뉴를 축소하여 터미널 작업 공간을 최대화하는 기능 추가. 상태는 `localStorage`에 저장되어 유지됨.

#### 변경 및 개선 사항 (Changed & Improved)
- **설정 UI 통합**: 터미널 모달로 흩어져 있던 설정을 메인 '환경 설정' 페이지로 통합하여 관리 편의성 증대.
- **테마 엔진 개선**: `xterm.js` 테마 적용 방식을 직접 속성 할당 방식으로 변경하여 호환성 문제 해결 및 렌더링 안정성 확보.
- **로그 정밀 추출**: 로그 저장 시 텍스트 버퍼를 엔터값 포함하여 정밀하게 추출하도록 로직 개선.
- **DB 스키마 확장**: 시스템 설정(`Config`) 및 명령어 스니펫(`Snippet`) 저장을 위한 테이블 추가 및 연동.

### [v1.1.0] - 2026-02-18
#### 추가된 기능 (Added)
- **자바스크립트 모듈화 (Refactoring)**: 거대한 `console.js`를 역할별로 5개 모듈(`common`, `terminal`, `sftp`, `editor`, `main`)로 분리하고 `PTSS` 전역 네임스페이스를 도입하여 코드 가독성과 유지보수성을 극대화함.
- **터미널 팝업(New Window) 기능**: 개별 터미널 세션을 별도 브라우저 창으로 띄울 수 있는 기능 추가. 탭 바에 팝업 전용 아이콘(`↗️`) 배치.
- **반응형 터미널 조절**: `ResizeObserver`를 도입하여 창 크기 변경이나 레이아웃 전환 시 터미널 크기(`fit`)가 자동으로 조절되도록 개선.

#### 변경 및 개선 사항 (Changed & Improved)
- **SFTP UI 정밀 보정**:
    - 파일 탐색기 헤더의 "권한" 토글 버튼 및 "정렬" 드롭다운의 높이(30px), 폰트, 수직 중앙 정렬(Baseline)을 픽셀 단위로 일치시킴.
    - 드롭다운 박스에 커스텀 SVG 화살표를 적용하여 브라우저 간 디자인 편차 해결.
    - 드롭다운 목록의 배경색을 지정하여 항목 가독성 문제 해결.
- **팝업 모드 레이아웃 최적화**:
    - 팝업 창 사용 시 불필요한 사이드바, 리사이즈 핸들, 헤더 정보 등을 숨겨 터미널 공간을 최대로 확보.
    - 하단 잘림 현상을 해결하기 위해 고정 높이 대신 `flex: 1` 기반의 유연한 레이아웃 적용.
- **코드 안정성**: 탭 닫기 시 메모리 누수 방지를 위한 `ResizeObserver` 해제 로직 추가.
