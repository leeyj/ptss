# PTSS 업데이트 히스토리

### [v1.5.1] - 2026-02-22
#### 추가된 기능 (Added)
- **데이터베이스 자동 마이그레이션 도구**: 
    - `tools/migrate_db.py`: 로컬/원격 DB의 스키마 변경사항(컬럼 추가 등)을 자동 감지하고 업데이트하는 스크립트 추가.
    - `tools/migrate_remote.py`: 운영 서버에 접속하여 마이그레이션을 원격으로 수행하는 자동화 도구 도입.
- **배포 제외 패턴 강화**: `deploy_ptss.py`에 `.venv_test`, `.venv`, `node_modules` 등 불필요한 개발용 디렉토리를 제외하는 로직을 추가하여 배포 속도와 운영 서버 안정성 개선.

#### 버그 수정 (Fixed)
- **터미널 접속 및 프롬프트 로딩 오류 수정**: `core/sockets.py`에서 누락된 핵심 모듈(`SSHManager`, `decrypt_data`) 임포트를 추가하고, 프론트엔드와 백엔드 간의 가드(Guard) 이벤트 명칭 불일치 문제를 해결하여 터미널 정상 작동 보장.
- **IP 추출 로직 안정화**: `get_client_ip` 호출 시 발생하던 인자 값 오류를 수정하여 로그인 및 명령어 감사 로그의 신뢰성 확보.


### [v1.5.0] - 2026-02-21
#### 추가된 기능 (Added)
- **AI 협업 팀 시스템 도입**: 단일 AI 에이전트 체제에서 **개발자, 테스터, 글쟁이**로 구성된 전문 AI 협업팀 체계로 전환.
    - **개발자**: 기능 구현 및 설계 책임.
    - **테스터**: 자동화 테스트 및 안정성 검증 담당.
    - **글쟁이**: 문서 최신화 및 사용자 가이드 관리 담당.
- **테스트 자동화 인프라 구축**:
    - `pytest`, `pytest-mock`, `pytest-cov` 기반의 유닛 테스트 환경 구축.
    - 가상 환경(`.venv_test`)을 활용한 격리된 테스트 수행 체계 마련.
    - `pyproject.toml` 설정을 통한 프로젝트 경로 자동화.
- **핵심 모듈 검증**: `core/crypto.py` 보안 로직에 대한 유닛 테스트(3종) 완료 및 통과.

#### 변경 및 개선 사항 (Changed & Improved)
- **리모트 서버 사양 분석**: 홈 서버(`***.***.***.***`)의 성능(H/W Specs) 분석 및 원격 개발 환경 최적화 제안.
- **보안 정책 강화**: 에이전트 규칙(`.agent/rules.md`) 업데이트를 통해 AI 팀별 역할 명시 및 보안 검토 절차 구체화.


### [v1.4.0] - 2026-02-21
#### 추가된 기능 (Added)
- **실시간 명령어 방화벽 (Interactive Guard)**: 위험 명령어(`rm -rf`, `shutdown` 등) 탐지 시 즉시 실행하지 않고 사용자에게 확인 팝업을 띄우는 보안 인터럽트 기능 구현.
- **터미널 세션 녹화 및 리플레이**: 모든 터미널 세션을 `asciinema` 호환 포맷으로 녹화하고, 히스토리 페이지에서 동영상처럼 복기할 수 있는 플레이어 통합.
- **녹화 데이터 최적화**: 세션 종료 시 녹화 파일을 Gzip으로 자동 압축하여 저장 공간을 80% 이상 절약.
- **자동 보관 주기 관리**: 관리자가 설정한 기간(3~365일)이 지난 구형 녹화 파일을 자동으로 클린업하는 기능 추가.

#### 변경 및 개선 사항 (Changed & Improved)
- **보안 감사 리포트**: 활동 히스토리에서 'SESSION' 액션 타입을 지원하며, 녹화 파일이 있는 항목은 '재생' 버튼을 통해 즉시 확인 가능하도록 개선.

### [v1.3.0] - 2026-02-21
#### 추가된 기능 (Added)
- **전역 다국어 지원 (Full Internationalization)**: 한국어와 영어(En)를 완벽하게 지원합니다. 브라우저 설정에 맞게 자동 감지하거나 설정에서 수동 변경 가능합니다.
- **JavaScript UI 다국어화**: 팝업 창, 확인 알림(confirm), 에러 메시지 등 JS로 구동되는 모든 동적 텍스트를 `window.I18N` 시스템으로 통합하여 현지화 완료.
- **서버 측 터미널 메시지 다국어화**: 터미널 연결 성공, 세션 복구, 명령어 제한 알림 등 백엔드에서 전송되는 시스템 메시지도 선택된 언어에 맞게 실시간 번역 지원.

#### 변경 및 개선 사항 (Changed & Improved)
- **배포 프로세스 최적화 (`deploy_ptss.py`)**: 원격 배포 후 서비스 재시작 시 백그라운드 프로세스 실행을 논블로킹(Non-blocking) 방식으로 개선하여 배포 완료 후 대기 현상을 해결함.
- **레이아웃 안정성 확보**: 다국어 리소스 로드 시점을 최적화하여 팝업이나 모달 창에서도 번역 정보가 즉각적으로 반영되도록 개선.
- **SFTP UI 로딩 피드백 개선**: 파일 목록을 불러오는 동안 표시되는 안내 메시지를 다국어 시스템과 연동하고 로딩 시 가독성 향상.

### [v1.2.0] - 2026-02-18
#### 추가된 기능 (Added)
- **세션 유지 및 자동 복구 (Persistence Layer)**: 브라우저 새로고침이나 일시적인 연결 끊김 시에도 서버 측에 터미널 세션과 출력 백로그(최근 2000줄)를 유지하여 작업 흐름을 완벽히 보존함.
- **명령어 스니펫(Snippet) 관리**: 자주 사용하는 명령어를 카테고리별로 저장하고 클릭 한 번으로 터미널에 전송하는 기능 추가. 단독 뷰 및 복합 뷰 모드 지원.
- **터미널 개인화 설정**: 환경 설정 메뉴를 통해 5종의 유명 테마(Default, Monokai, Dracula 등)와 폰트 종류, 크기(10~24px)를 자유롭게 변경 가능.
- **터미널 로그 저장**: 각 터미널 탭에 '저장(💾)' 버튼을 추가하여 현재 세션의 모든 입출력 내역을 `.txt` 파일로 다운로드 가능.
- **사이드바 토글(Collapse)**: `☰` 버튼을 통해 왼쪽 메뉴를 축소하여 터미널 작업 공간을 최대화하는 기능 추가. 상태는 `localStorage`에 저장되어 유지됨.

#### 변경 및 개선 사항 (Changed & Improved)
- **설정 UI 통합**: 터미널 모달로 흩어져 있던 설정을 메인 '환경 설정' 페이지로 통합하여 관리 편의성 증대.
- **테마 엔진 개선**: `xterm.js` 테마 적용 방식을 직접 속성 할당 방식으로 변경하여 호환성 문제 해결 및 렌더링 안정성 확보.
- **로그 정밀 추출**: 로그 저장 시 텍스트 버퍼를 엔터값 포함하여 정밀하게 추출하도록 로직 개선.
- **DB 스키마 확장**: 시스템 설정(`Config`) 및 명령어 스니펫(`Snippet`) 저장을 위한 테이블 추가 및 연동.

### [v1.1.0] - 2026-02-18
#### 추가된 기능 (Added)
- **자바스크립트 모듈화 (Refactoring)**: 거대한 `console.js`를 역할별로 5개 모듈(`common`, `terminal`, `sftp`, `editor`, `main`)로 분리하고 `PTSS` 전역 네임스페이스를 도입하여 코드 가독성과 유지보수성을 극대화함.
- **터미널 팝업(New Window) 기능**: 개별 터미널 세션을 별도 브라우저 창으로 띄울 수 있는 기능 추가. 탭 바에 팝업 전용 아이콘(`↗️`) 배치.
- **반응형 터미널 조절**: `ResizeObserver`를 도입하여 창 크기 변경이나 레이아웃 전환 시 터미널 크기(`fit`)가 자동으로 조절되도록 개선.

#### 변경 및 개선 사항 (Changed & Improved)
- **SFTP UI 정밀 보정**:
    - 파일 탐색기 헤더의 "권한" 토글 버튼 및 "정렬" 드롭다운의 높이(30px), 폰트, 수직 중앙 정렬(Baseline)을 픽셀 단위로 일치시킴.
    - 드롭다운 박스에 커스텀 SVG 화살표를 적용하여 브라우저 간 디자인 편차 해결.
    - 드롭다운 목록의 배경색을 지정하여 항목 가독성 문제 해결.
- **팝업 모드 레이아웃 최적화**:
    - 팝업 창 사용 시 불필요한 사이드바, 리사이즈 핸들, 헤더 정보 등을 숨겨 터미널 공간을 최대로 확보.
    - 하단 잘림 현상을 해결하기 위해 고정 높이 대신 `flex: 1` 기반의 유연한 레이아웃 적용.
- **코드 안정성**: 탭 닫기 시 메모리 누수 방지를 위한 `ResizeObserver` 해제 로직 추가.
