# 2차 고도화 구현 계획: 계정 관리 DB화 및 초기 설정 프로세스 ✅ (완료)

## 1. 개요
현재 PTSS는 서버 기동 시 `.env` 설정에 기반하여 관리자 계정을 자동으로 생성합니다. 이를 중단하고, 데이터베이스 중심의 계정 관리와 최초 접속 시 설정을 완료하는 '설정 마법사'를 도입합니다.

## 2. 주요 작업 단계

### Phase 1: 시스템 보호 및 리디렉션 로직 ✅
- [x] 데이터베이스에 사용자가 하나도 없을 경우 모든 접근을 `/setup` 페이지로 강제 리디렉션하는 미들웨어/데코레이터 로직 구현.
- [x] `ptss.py` 내 자동 관리자 생성 로직(`db.create_all()` 이후 섹션) 제거.

### Phase 2: 설정 마법사 (Setup Wizard) ✅
- [x] `/setup` 라우트 및 `setup.html` 템플릿 구현.
- [x] 관리자 계정 정보(ID/PW) 입력 및 DB 저장 로직.
- [x] '마스터 키' 설정 기능:
    - [x] 기존 `.env` 키 사용 여부 확인. (현재 DB 우선으로 고도화 완료)
    - [x] 새로운 키 생성 및 가이드 제공. (DB 저장 및 .env 배제 완료)

### Phase 3: 사용자 관리 패널 및 호스트 보안 고도화 ✅
- [x] 호스트 등록 시 실시간 SSH 연결 테스트 및 검증 로직 추가.
- [x] 호스트 비밀번호 및 개인키 암호화 저장 로직 구현.
- [x] 연결 실패 시 전용 에러 안내 페이지(error.html) 제공.
- [x] 마스터 키의 DB 저장 및 .env 의존성 완전 제거.

### Phase 4: 초기 설정 및 관리 도구 ✅
- [x] 명령어 스니펫 기록 자동화 및 스크립트 실행 히스토리 보강.
- [x] AJAX 기반의 호스트 추가/삭제 UX 개선.

## 3. 세부 기술 요구사항 ✅
- **보안**: 설정 마법사는 사용자가 하나도 없을 때만 활성화되어야 함.
- **사용자 경험**: 깔끔하고 직관적인 'Setup' UI 제공.
- **호환성**: 기존 유저 데이터가 있을 경우 영향이 없어야 함.
