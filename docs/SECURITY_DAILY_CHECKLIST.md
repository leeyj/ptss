# 🛡️ PTSS 일일 보안 점검 체크리스트 (Daily Security Checklist)

보안은 시스템의 기능보다 중요합니다. 매일 작업을 시작하거나 종료할 때 다음 항목을 반드시 확인하십시오.

## 1. 코드 및 설정 (Code & Config)
- [ ] **`.env` 파일 확인:** 외부로 노출되지 않았는지, `.gitignore`에 제대로 등록되어 있는지 확인합니다.
- [ ] **하드코딩된 정보:** 소스 코드 내에 IP 주소, 도메인, 계정 이름, 비밀번호가 직접 적혀 있지 않은지 확인합니다.
- [ ] **테스트 파일 제거:** `test_sensitive.py`와 같이 테스트를 위해 임시로 생성한 민감한 파일이 남아있는지 확인하고 삭제합니다.

## 2. Git 저장소 (Git Repository)
- [ ] **Staged Files:** `git add` 된 파일 중에 의도하지 않은 설정 파일이나 로그 파일이 포함되어 있지 않은지 확인합니다.
- [ ] **최근 커밋 이력:** 방금 푸시한 커밋에 민감한 정보가 포함되지 않았는지 다시 한번 복기합니다.

## 3. 홈 서버 보안 (Home Server)
- [ ] **Nginx 로그 모니터링:** 비정상적인 IP로부터의 접근 시도가 있는지 확인합니다.
- [ ] **포트 개방 환경:** 꼭 필요한 포트(80, 443) 외에 불필요하게 열려있는 포트가 없는지 확인합니다.
