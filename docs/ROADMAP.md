## [2차 고도화 계획]

### 1. 계정 관리의 완전한 DB화 및 초기 설정 프로세스 ✅ (완료)
- **목표**: 코드나 환경 변수에 의존하지 않고 모든 계정 정보를 DB에서 독립적으로 관리.
- **주요 내용**: 
  - 최초 접속 시 관리자(Admin) 계정 설정 마법사 제공 (기존 코드 내 자동 생성 로직 제거). ✅
  - 관리자 패널에서 사용자 계정 생성, 수정, 삭제 기능 강화. ✅
  - 데이터베이스 스키마 및 마스터 키(.env) 자동 생성 도구. ✅
  - 호스트 등록 시 실시간 검증 및 암호화 고도화. ✅

### 2. 사용자별 명령어 제한(Restricted Shell) 설정 ✅ (완료)
- **목표**: 보안 강화를 위한 사용자별 실행 권한 세밀 제어.
- **주요 내용**:
  - 관리자 패널에서 일반 사용자가 실행할 수 없는 명령어/키워드 블랙리스트 설정. ✅
  - 특정 사용자에 대한 실시간 명령어 필터링 및 차단 로그 기록. ✅

### 3. 활동 히스토리 및 감사 로그(Audit Log) 강화 ✅ (완료)
- **목표**: 관리자의 시스템 모니터링 및 보안 감사 능력 향상.
- **주요 내용**:
  - 사용자별 세션 시작/종료 내역 및 실행 명령어 상세 조회. ✅
  - 시간대별, 사용자별, 호스트별 히스토리 검색 및 필터링 강화. ✅
  - 특정 액션(SSH 접속 실패 등)에 대한 통계 시각화. ✅

### 4. 대용량 출력 성능 최적화 ✅ (완료)
- **목표**: 긴 스크롤 및 대량 로그 출력 시 브라우저 부하 방지.
- **주요 내용**:
  - **xterm-addon-webgl** 도입을 통한 GPU 가속 렌더링. ✅
  - 터미널 메모리 사용량 관리 및 가상 스크롤 최적화. ✅

### 5. 인프라 보안 자동화 (HTTPS/SSL)
- **목표**: 서비스 배포 시 보안 통신 환경 구축의 편의성 제공.
- **주요 내용**:
  - `tools/generate_ssl.py`: 개발/내부망 테스트용 자체 서명 인증서 자동 생성 도구.
  - 대중적인 리버스 프록시(Nginx, Caddy)용 설정 템플릿 자동 생성 가이드.

## [3차 고도화: 기업용 특권 권한 관리(PAM) 비전]

💡 **상세 실행 계획서**: [PLAN_ENHANCEMENT_V3_PAM.md](./PLAN_ENHANCEMENT_V3_PAM.md)

PTSS의 궁극적인 목표는 단순한 SSH 클라이언트를 넘어, 기업 내 인프라의 관문(Gateway)으로서 강력한 통제와 보안을 제공하는 것입니다.

### 1. 실시간 세션 녹화 및 리플레이 (Audit Recording) ✅ (완료)
- **목표**: 텍스트 로그를 넘어 터미널의 모든 입출력을 시각적으로 복기.
- **주요 내용**:
  - 터미널 스트림(Asciiprocast format) 바이너리 및 Gzip 압축 저장. ✅
  - 관리자 패널에서 과거 세션을 동영상처럼 재생하는 리플레이어 구현. ✅
  - 자동 보관 주기 관리 엔진 구현. ✅

### 2. 엔터프라이즈 명령어 방화벽 (Command Guard) ✅ (완료)
- **목표**: 휴먼 에러 및 악의적인 명령어 실행 사전 차단.
- **주요 내용**:
  - `rm -rf /`, `reboot`, `shutdown` 등 위험 키워드 실시간 탐지. ✅
  - 위험 명령어 실행 시 사용자에게 경고 및 재확인(Interactive Confirm) 절차 구현. ✅

### 3. 일시적 권한 승인 (JIT - Just-In-Time Access)
- **목표**: 상시 권한 제거를 통한 보안 최소화(Zero Trust).
- **주요 내용**:
  - 필요할 때만 일정 시간(예: 1시간) 동안 접속 권한을 요청/승인하는 워크플로우.
  - 승인 시간 종료 시 세션 강제 종료 및 임시 자격 증명 회수.

### 4. 클러스터 및 일괄 제어 (Cluster Execution)
- **목표**: 수십/수백 대의 서버에 대한 동시 운영 효율성 확보.
- **주요 내용**:
  - 다수의 호스트를 선택하여 동일 명령어/스크립트를 일괄 실행하고 결과를 취합.
  - 인프라 패치, 상태 점검 등을 위한 자동화 대시보드.

## [인프라 및 연결성 확장]
- **SSO 연동**: LDAP, Active Directory, Google Workspace 계정 연동.
- **클라우드 연동**: AWS, GCP, Azure API를 통한 인스턴스 목록 자동 동기화.
- **모니터링 강화**: SSH 접속 전 서버 부하 상태(CPU/MEM) 사전 시각화.

## [부가 기능 도입 계획]
- **Search Addon**: 터미널 내 텍스트 검색 (Ctrl+F).
- **Web Links Addon**: 터미널 내 URL 및 경로 클릭 시 자동 연결.
- **Mobile Optimized Web**: 태블릿 및 모바일 기기를 위한 터치 인터페이스 개선.
