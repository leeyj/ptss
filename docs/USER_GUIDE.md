# PTSS 사용자 가이드 (User Guide)

이 문서는 PTSS(Premium Terminal & SFTP System)의 기본적인 사용 방법과 관리 기능을 설명합니다.

---

## 1. 초기 설정 (Initial Setup)
서비스를 처음 실행하면 **초기 설정 마법사**가 나타납니다.
1. **관리자 계정 생성**: 시스템 전역 관리 권한을 가진 마스터 계정을 생성합니다.
2. **마스터 키 확인**: SSH 비밀번호 및 개인키 암호화에 사용될 마스터 키가 생성됩니다. (이 키는 `.env` 파일에 저장되며, 분실 시 데이터 복구가 불가능할 수 있으니 주의하십시오.)
3. **언어 설정**: 초기 설정 완료 후 메인 대시보드 진입 시 시스템 언어가 브라우저 로케일에 맞춰 자동 설정됩니다.

## 2. 전역 설정 및 다국어 지원 (Settings & I18N)
PTSS는 글로벌 환경을 위해 한국어와 영어(En)를 완벽하게 지원합니다.
- **언어 변경**: 상단 바의 프로필 메뉴 또는 `환경 설정(Settings)` 페이지에서 즉시 언어를 전환할 수 있습니다.
- **테마 및 폰트**: 개인별 최적화된 테마(Dracula, Monokai 등)와 폰트 크기/종류를 브라우저 세션에 저장하여 유지합니다.
로그인 후 첫 화면에서는 등록된 서버들의 상태를 확인할 수 있습니다.
- **호스트 추가 (Admin)**: `+ Host` 버튼을 눌러 관리할 서버의 IP, SSH 포트, 계정 정보(ID/PW 또는 Key)를 입력합니다.
- **모니터링**: 각 호스트 카드의 실시간 CPU/RAM 그래프를 통해 서버 부하 상태를 즉시 파악할 수 있습니다.
- **접근 제어**: 특정 사용자에게 특정 호스트에 대한 접근 권한만 부여할 수 있습니다.

## 3. 웹 터미널 사용법
호스트 카드의 `Connect` 버튼을 클릭하면 터미널 탭이 열립니다.
- **멀티 탭 지원**: 여러 서버에 동시 접속하여 탭으로 전환하며 작업할 수 있습니다.
- **커스터마이징**: 상단 설정 아이콘을 눌러 테마와 폰트 크기를 개인 취향에 맞게 조정하십시오.
- **리사이징**: 브라우저 창 크기를 조절하면 터미널 화면이 자동으로 최적화됩니다.
- **로그 다운로드**: 세션 종료 전 상단의 `저장(💾)` 버튼을 눌러 현재까지의 작업 내역을 `.txt` 파일로 내려받을 수 있습니다.
- **팝업 뷰 (New Window)**: 특정 터미널 탭을 브라우저 새 창으로 분리하여 멀티 모니터 환경에서 효율적으로 작업할 수 있습니다. (`↗️` 아이콘 클릭)

## 4. SFTP 파일 관리
터미널 우측(또는 하단)의 SFTP 패널을 통해 파일을 조작할 수 있습니다.
- **업로드/다운로드**: 로컬 파일을 드래그하여 패널에 놓으면 업로드됩니다. 정적 다운로드 버튼 아이콘을 클릭하여 파일을 내려받을 수 있습니다.
- **텍스트/로그 미리보기**: 서버의 로그 파일이나 설정 파일(`🔍` 아이콘)을 눌러 브라우저 전용 팝업 창에서 즉시 내용을 확인하고 수정할 수 있습니다.
- **정렬**: 이름순, 유형순, 날짜순 정렬 옵션을 통해 수많은 파일 중 원하는 항목을 빠르게 찾을 수 있습니다.

## 5. 명령어 스니펫 (Snippet)
자주 사용하는 복잡한 명령어는 스니펫으로 등록해 관리하십시오.
- **등록**: `Add Snippet` 메뉴에서 명령어와 설명을 등록합니다.
- **실행**: 터미널 탭에서 우측 스니펫 패널을 열고, 원하는 명령어를 클릭하면 터미널에 즉시 입력됩니다.
- **제한**: 커뮤니티 버전 사용자는 최대 10개까지 저장 가능하며, 엔터프라이즈 버전은 무제한입니다.

## 6. 활동 히스토리 (Audit Log)
보안 감사 및 이력 관리를 위해 모든 활동이 기록됩니다.
- **조회**: 상단 메뉴의 `History` 탭에서 확인 가능합니다.
- **권한**: 관리자는 전체 기록을, 일반 사용자는 본인의 기록만 볼 수 있습니다.
- **필터링**: 특정 날짜, 특정 호스트, 특정 명령어를 검색하여 과거 기록을 추적하십시오.
